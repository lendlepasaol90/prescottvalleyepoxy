# Prescott Valley Epoxy

Source for prescottvalleyepoxy.com. Pages are generated by `build.mjs` into `public/` and served by a Cloudflare Worker (`src/worker.js`), which also receives the estimate form at `/api/lead`.

## Pages

- `/`
- `/garage-epoxy/`
- `/residential-floors/`
- `/decorative-flake/`
- `/metallic-epoxy-floors/`
- `/polyaspartic-floors/`
- `/polyurea-floors/`
- `/outdoor-concrete-coatings/`
- `/business-floor-coatings/`
- `/our-story/`
- `/service-areas/`
- `/contact/`
- `/privacy-policy/`

Service pages live in `src/content/services/` (one file per page, registered in `index.mjs`).

## Working on it

## Still to do before this can rank

- **Phone number** is a placeholder. Edit `phone` / `phoneHref`, then set `phoneVerified: true` in `src/site.mjs`. Until then the number is left out of the structured data.
- **Lead delivery**: set `LEAD_WEBHOOK_URL` or `WEB3FORMS_ACCESS_KEY` on the Worker.
- **Real proof**: job photos, reviews, license and insurance details belong to whoever operates the business. Do not add invented ones.

Old URLs from the first launch 301 to their new paths via the `REDIRECTS` map in `src/worker.js`.
