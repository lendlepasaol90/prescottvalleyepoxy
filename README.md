# Prescott Valley Epoxy

Website for **https://prescottvalleyepoxy.com** — a static site generated by a small, dependency-free Node build, served by a Cloudflare Worker that also handles the lead forms.

## Structure

```
build.mjs                 Builds every page into ./public
src/site.mjs              Business details, phone, service areas, map centre, image list  ← edit first
src/content/services/     One file per service page (content + FAQs)
src/templates/            Layout, header/footer, homepage, service and simple pages
src/assets/               CSS and JS (copied to /public/assets)
src/worker.js             Cloudflare Worker: /api/lead form endpoint + static assets
scripts/check.mjs         QA: word counts, meta, headings, links, duplicate text
public/                   Built output (committed, ready to deploy)
wrangler.jsonc            Worker + static assets config
```

## Commands

```
npm run build    # regenerate ./public
npm run check    # quality checks (word counts, SEO tags, broken links, duplicate copy)
npm run deploy   # build and deploy with Wrangler
```

No `npm install` is needed to build. Wrangler is only needed to deploy from the command line; a Git-connected Cloudflare Workers build can use build command `node build.mjs` and deploy command `npx wrangler deploy`.

## Before launch

1. **Phone number** — `src/site.mjs` uses the placeholder `(928) 555-0139`. Replace `phone` and `phoneHref`, then set `phoneVerified: true` so it is added to structured data.
2. **Lead delivery** — in Cloudflare (Worker → Settings → Variables and secrets) set one of:
   - `LEAD_WEBHOOK_URL` — any URL that accepts a JSON POST (Zapier, Make, Formspree, CRM webhook), or
   - `WEB3FORMS_ACCESS_KEY` — free email delivery via web3forms.com.
   Leads are always written to the Worker logs as a backup.
3. **Logo and favicon** — replace the dashed placeholder in `src/templates/parts.mjs` (`mark`) and add favicon links in `src/templates/layout.mjs`.
4. **Custom domain** — attach `prescottvalleyepoxy.com` and `www` to the Worker (www redirects to the apex automatically).

## Images

Photos are licensed from Envato Elements (registered to this site) and self-hosted as responsive WebP files in `src/assets/img/` (`<key>-<width>.webp`). Each entry in `src/site.mjs → images` lists its file key, original size, generated widths and alt text. To swap a photo, add new `<key>-480/800/1200/1600.webp` files and update the entry.

## Content rules

No invented reviews, testimonials, awards, years in business, licences or addresses. The footer map is centred on Prescott Valley without claiming an office location.
